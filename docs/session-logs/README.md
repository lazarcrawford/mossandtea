# Session Logs

This directory is the durable session memory for Moss & Tea work.

Each log is reconstructed from Git history, PR state, deployment notes, and the working session record. Chat may explain context, but GitHub is the durable source of truth:

- code changes live in commits and pull requests
- open decisions live in GitHub Issues with the `decision` label
- operational gaps live in docs and GitHub Issues
- local-only patches or loose planning files are not accepted as project memory
